# treak.se

Static website for Treak AB, served by GitHub Pages on the custom domain `treak.se`.

- `index.html` – landing page, `integritetspolicy.html` – privacy policy
- `style.css` – Treak brand tokens (Slate Teal `#53808A`, accent `#EA7A41`, Urbanist), same values as the platform's `tokens.css`
- `fonts/` – Urbanist, self-hosted so the site loads nothing from third parties

Edit the files and push to `main`; Pages publishes within a minute.
